# 📦 3D Text STL Studio (GitHub Pages Web App)

Convert text using fonts from **daFont** or custom `.TTF` / `.OTF` files into **3D printable STL files** right in your browser!

Visit the website here: [https://alanrosenthal.github.io/3d-text-generator/](https://alanrosenthal.github.io/3d-text-generator/)
